## What was built

`src-tauri/src/diagrams.rs`. The model is asked for a **graph, not prose**, and that changes what failure means: a rambling paragraph where a node list belongs is not a diagram with problems, it is not a diagram.

- **Strict JSON or nothing.** Models wrap JSON in code fences and in "Here is the graph:" no matter how firmly the prompt says not to, so the first balanced object is extracted — correctly, through nested braces and quoted braces inside strings. But if what comes out is not a graph, the result is an **error carrying the model's actual reply**, not an empty canvas the author has to interpret.
- **Every document reference is resolved against the real binder**, by id or by title (models answer with titles). A node claiming a document that is not in the project keeps its label and **loses the false claim**, and the drop is reported.
- **Edges into nothing are dropped**, as are self-edges and duplicate ids. Everything dropped is listed in the diagram and shown in the UI. A diagram that quietly loses half its content while looking complete is worse than one that admits what it left out.
- **Rendered with the existing SVG helpers.** A ring layout, no charting dependency. Force-directed would look better and would also mean shipping a physics engine to draw twelve circles.
- **Saved as Markdown with a Mermaid block** — the author owns it, any editor opens it, GitHub renders it, and the note under it says whose reading it is.

### Verified live

`llama3.2:3b` — a 3-billion-parameter model — returned a valid 15-node, 23-edge mind map with **nothing dropped**. The live test records what happens rather than asserting that every model can hold a JSON shape; that is a fact about the model, not about this code.
