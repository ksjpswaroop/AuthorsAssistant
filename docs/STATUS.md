## Phase by phase

Every phase is verified: `scripts/verify.sh` does a clean rebuild, clippy, the
full test suite, a typecheck, the frontend tests and a production build, and
prints `RESULT: PASS` only if all of them pass.

### Phase 1 — Core editor · **complete**
Project folders, SQLite + Markdown, binder, TipTap, atomic autosave, trash.
Prose is readable without the app; proven by a test that reads the file directly.
**Security-scoped bookmarks** now back the recent-projects list, so a sandboxed
build can reopen a project on its second launch — that was the App Store blocker.

### Phase 2 — Scrivener features · **complete**
Drag-and-drop binder (`react-arborist`), corkboard (`dnd-kit`), outliner
(TanStack Table v8), synopsis/label/status/notes/POV/target/keywords, character
and location sheets, canon entries, LibGit2 snapshots with restore, and
**import** of an existing folder of Markdown that mirrors the directory tree and
can never overwrite prose already in the project.

### Phase 3 — Local AI + RAG · **complete**
Ollama client, generation, chunking, embedding, an index in the project's own
SQLite, cosine search, an assist panel, a **Search** screen over the whole book,
and a **style profile** measured from the prose the author marked Done, injected
into rewrite and continue so "in my voice" is a measurement rather than a label.
*Verified live:* embeddings deterministic at 1024 dims; "who was hurt, and who
treated the injury?" returns the surgeon scene.

### Phase 4 — Integrity · **complete**, with one goal cut
Internal similarity by word shingles, prose measurements, rubric scoring — all
local, no model needed. Web similarity through the author's own **wigolo**
daemon, phrase-scoped and confirm-gated, with every request traced. An
exportable **integrity packet** as JSON + HTML carrying the method notes.
*Cut:* AI-writing detection. Binoculars needs token log-probabilities Ollama does
not expose, and a bundled classifier is wrong often enough to ruin someone with
no way to appeal. The measurements stay; the verdict is not ours to give.
wigolo now runs as a **managed sidecar**: AegisDraft resolves, starts,
health-gates and stops it, and it dies with the app. Verified live against
wigolo 0.2.1 — started through npx, real search, real results, clean stop.
See [SIDECAR.md](SIDECAR.md).

### Phase 5 — Agents · **complete**, without hermes-agent
A real tool-calling loop against Ollama's `/v1/chat/completions`, driving the
16-tool gateway. Four profiles, each a system prompt **plus a tool subset** — a
World-Builder that is not given `delete_document` cannot delete however it is
prompted. A guarded tool **pauses** the run with nothing executed until a person
answers, and declining feeds the refusal back so the model can carry on. Traces
in `traces/` as readable JSON; the inspector reads them.
*Verified live:* `llama3.2:3b` one hop, `qwen3.5:cloud` two hops carrying state
between them. *Dropped:* hermes-agent, the FastAPI gateway, and skill growth.

### Phase 6 — Scrivener completeness · **complete**, minus bookmarks
Collections, editable Scrivenings, section types, bulk metadata, composition
mode, a real **snapshot diff** by paragraph, **writing goals** stored with the
project, four **project templates**, an **editable** second pane, the **freeform
corkboard**, and **custom binder icons**.
*Not built:* cross-document bookmarks pane; custom sheet templates.

### Phase 7 — Compile and export · **complete**
Markdown, HTML, DOCX, EPUB, Fountain, with section-type layout rules, presets and
filters. Archives are verified by unzipping them in tests. `compile_manuscript`
is a guarded agent tool.
*By design:* PDF exports print-ready HTML; the OS print pipeline makes the PDF,
because this build does not bundle a typesetting engine.

### Phase 8 — Story visualization · **complete**
Beats, dual-order timeline with gap detection, character graph, and a
**draggable canvas that commits back to the binder** — behind a plan the author
sees first, and a snapshot taken before the reorder.
*Not built:* notes, images and arrows on the canvas; graph filters by act.

### Phase 9 — Advanced visualization · **complete**
Pacing, gap analysis, clustering into collections — all with no model. **Mind
maps, flowcharts and reference sheets** generated by a local model from the
binder, validated against a strict shape, and saved as Markdown with a Mermaid
block.
*Verified live:* `llama3.2:3b` returned a valid 15-node, 23-edge mind map with
nothing dropped.

## Models

Two pools, kept apart because mixing them fails in a way that looks like a broken
feature rather than a wrong choice:

- **Generation** — writes prose. An embedding model asked to generate returns an
  empty string.
- **Embedding** — indexes and searches. A chat model asked to embed is refused by
  Ollama with a message that blames the server.

`generation_and_embedding_pools_never_overlap` asserts the split; five frontend
tests mirror it.

### Reasoning models

Models like `qwen3.5:397b-cloud` put their chain of thought in a `thinking` field
and leave `response` empty until they finish — which, on a real prompt, never
happens inside a sane token budget. The client sends `think: false`, and an empty
answer now explains which of the two things went wrong instead of surfacing as an
empty string.

### Cloud models

A `:cloud` tag is proxied to a remote service. Using one **sends the manuscript
off the machine**, which is the one thing this product promises not to do.

- Never chosen automatically, and excluded from every automatic pool.
- `generate_guarded` refuses without explicit consent, below the UI, so no future
  caller can reach one by accident.
- The assist panel lists them under **"Somewhere else"** behind an off-by-default
  switch, and the run button reads *"Send to qwen3.5:397b-cloud"*.

This is supported because it was asked for, and built so it can never happen
quietly. The golden rule in [ARCHITECTURE.md](ARCHITECTURE.md#golden-rule) has
been rewritten to describe what the code actually enforces — it used to promise
no cloud fallback while the app already shipped one, and a promise the code does
not keep is worse than a narrower promise it does.

## Deep Continuity · **built**

The four tools named in [AGENTS.md](AGENTS.md) that had no implementation. The
Continuity profile was approximating them with `read_document` and
`search_binder`, which finds *similar* passages but cannot find *contradictory
facts*.

- `extract_entities` — characters, places and dates, matched against the
  author's own sheets first. A name without a sheet is not guessed at.
- `check_against_canon` — which established facts a scene stands near. Retrieval,
  and it says so: deciding from word overlap would call "his left leg" and "his
  right leg" a match.
- `check_foreshadowing_ledger` — plants with no payoff, payoffs with nothing
  planted. Pure arithmetic over fields the inspector already has.
- `log_propagation_debt` — writes down a hole in the world instead of inventing
  a fact to fill it. A model that answers "what colour are the guild robes" by
  choosing one has become the author of the world's rules.

All of it runs with no model and no network. Story → **Continuity**.

## Knowledge to Publication · **built**

The K2P-OS object model on our own stack — Tauri, SQLite, Markdown, Ollama, local
by default — with its nine-service cloud mapping rejected.

- **Block identity** (`blocks.rs`) — stable paragraph ids, content-anchored so
  they survive rewriting, reordering and editing the file in vim.
- **Provenance ledger** (`provenance.rs`) — append-only, hash-chained, with
  authorship *derived from events* rather than inferred from prose. This is the
  honest replacement for the AI detection cut in Phase 4: where there is no
  record, the report says so instead of assuming a human wrote it.
- **Sources** (`sources.rs`) — ingestion, extraction, metadata, deduplication,
  generated citations.
- **Knowledge** (`knowledge.rs`) — claims verified word-for-word against their
  source, two-stage contradiction detection, gap analysis, and the retraction
  query that names every paragraph resting on a source.
- **Deep research** (`research.rs`) — decompose, gather, extract, verify,
  synthesise with citations that are checked before they are shown.

## Known gaps, in priority order

1. **UI interaction is untested.** Drag-and-drop, dialogs, menus and buttons have
   tested backends but no automated UI coverage: macOS denies this environment
   both keystrokes and clicks. Granting Accessibility to the terminal unblocks
   it. Everything below the UI is covered; the clicking is not, and this document
   will keep saying so until it is.
2. **The wigolo sidecar is Unix-only, and not for the App Store.** Windows has
   no process-group kill in this implementation, so it would orphan the daemon
   the Unix path handles; a sandboxed build cannot reach `npx` or drive a
   headless browser. Integrity works offline in both cases, and the Web tab
   simply stays unavailable.
3. **Images on the canvas.** Notes and arrows are built; pasting an image is
   not, and it would mean an asset store the project does not have.

### Deliberately not built, with the reason

- **Publishing channels** (KDP, IngramSpark, Apple Books) — a distribution
  business surface, not a local-first authoring one.
- **C2PA credentials, Merkle roots, signing** — the ledger is tamper-*evident*;
  tamper-*proof* needs a signing identity and an external timestamp.
- **Cross-document block tracking** — a paragraph moved between chapters is a
  delete and a create. Project-wide matching on every save has a false-positive
  rate bad enough to make the feature dishonest.
- **Agent skill growth** — hermes-agent's feature, and hermes-agent was dropped
  as unnecessary once Ollama's native tool calling was confirmed.
- **OCR, Zotero and Crossref connectors** — real, and not yet.

## Bugs a live run found that stub tests could not

- **The wigolo sidecar leaked a daemon on every stop.** `npx wigolo` runs the
  real server as a grandchild, so killing the handle we held left node orphaned
  onto init — still serving, still holding the port — while `stop()` reported
  success. Fixed by spawning into its own process group, signalling the group,
  and having `stop()` **verify** rather than assume. A stop that does not check
  is a stop that can lie. See [SIDECAR.md](SIDECAR.md).
- **wigolo's live response shape is not the one in its README.** It sent
  `snippet` with an `evidence_score` and no `citation_id` or `source_span` — the
  REST-reference shape. Parsing both is what made the first live query work.

## Bugs a live model found that stub tests could not

- `llama3.2:3b` sends `"parent_id": ""` rather than omitting an optional field.
  That empty string reached SQLite, which answered `FOREIGN KEY constraint
  failed` — an error about the author's database for what was really a model
  filling in a blank. The gateway now treats a blank optional string as absent.
- A reasoning model returns its output in `thinking` and leaves `response` empty.
  The client sends `think: false`.

## Bugs the type system was hiding

- `IconName` was `keyof typeof PATHS` over a `Record<string, ReactNode>`, which
  widens to `string`. Every icon name typechecked, including wrong ones, and a
  wrong one rendered an empty box.
- The TypeScript `DocumentRow` had drifted from the Rust struct: `sectionType`
  and `icon` existed in SQLite and in Rust for a whole phase without ever
  appearing in the frontend type.
- Vocabulary range in the style profile fell back to a whole-text type/token
  ratio below its window, then compared that against a windowed profile value —
  reporting a *length* difference as a *style* difference.
